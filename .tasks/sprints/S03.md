# Sprint S03 — 2026-10-07 a 2026-10-28

Milestone: **M2** (Gerenciador de arquivos padrão no Linux)

**Meta:** WingDrive vira o file manager padrão na máquina do autor: abre pastas pelo `xdg-open` e
por outros apps, fica residente na bandeja e cobre as operações básicas de um file manager.

## Log

- 2026-10-07: sprint aberto por decisão do usuário. Primeiro launch do `wingdrive-bin` alpha.8 expôs os
  problemas da TAURI-015; o levantamento do que falta para substituir Dolphin/Yazi virou o épico DESK-000.
- 2026-10-08: CORE-014 auditada e em In Progress (Linux e comandos Tauri marcados com evidência; macOS/Windows
  dependem de máquina real). Ícones dos apps no "Abrir com" (DESK-004), Enter abre a seleção, abrir vários arquivos.
- 2026-10-08: INDEX-011 (varredura efêmera completa, sem regras, para file sync) e INDEX-012 (navegar sob
  uma raiz indexada recursivamente reaproveita o índice, com caminhos canônicos/symlinks) concluídas.
- 2026-10-09: DEV-004 (fora do compromisso). Os dois superaquecimentos do NVMe em 08/10 vieram dos builds
  Rust: `target/` com 266 GB e 77 caches incrementais do `wing_core`. As receitas do `just` passaram a usar as mesmas
  features, o `xtask setup` limita `jobs` à metade das CPUs e `just clean-stale` limpa os caches velhos.
- 2026-10-14: DESK-012. A navegação lenta no Linux vinha de 14 `backdrop-filter` (efeito vidro) recompostos
  a cada troca de pasta no WebKitGTK, e de um menu de contexto montado por item (mutations + query "Abrir com").
  A janela principal no Linux agora fica sem vidro e o menu é criado sob demanda: mediana de ~450 ms para ~55 ms
  por navegação no binário release instalado, com ~4x menos CPU do renderer.
- 2026-10-15: DESK-014 (PR #205): tamanho real das pastas, com cálculo sob demanda opcional no Explorer.
  FORK-006 item 1 (watcher da biblioteca para antes do `close_all`) e DESK-013 passos 1 e 2 (bandeja
  traduzida, links do Sobre no navegador do sistema).
- 2026-10-15: INDEX-013 (fora do compromisso): a `entry_closure` perdia a linha "pasta mãe → filho" quando
  os dois eram indexados no mesmo lote. Correção na inserção e migration que repara bibliotecas existentes.
