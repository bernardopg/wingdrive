## Description

A location covering the home or root directory also covers WingDrive's databases, thumbnails, and job state. Processing changes generated by WingDrive itself can create an indexing and thumbnail feedback loop that fills the volume.

## Implementation Steps

- [x] Add component-aware excluded directory trees to watcher filters
- [x] Apply the WingDrive data directory exclusion to persistent and ephemeral watches
- [x] Verify focused tests and workspace compilation

## Acceptance Criteria

- Events under the configured WingDrive data directory are dropped before broadcast
- Similar path names outside that directory are not dropped
- The exclusion applies when watching a parent such as the home or root directory
