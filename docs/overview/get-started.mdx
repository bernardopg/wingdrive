WingDrive indexes your folders, external drives and cloud volumes into one library. This guide installs it, creates your first library, adds folders and connects the rest of your storage. It takes about ten minutes.

The [user guide on wingdrive.org](https://wingdrive.org/docs/) covers the same steps with more screenshots, in English and Portuguese.

## Install WingDrive

WingDrive runs a background service (the daemon) and a separate window. Closing the window does not stop indexing or sync.

| Platform | How |
|---|---|
| Arch Linux and derivatives | `yay -S wingdrive-bin` (stable) or `yay -S wingdrive-nightly` (every release, including alpha, beta and rc) |
| Any Linux (x86_64) | AppImage or `.deb` from [Releases](https://github.com/bernardopg/wingdrive/releases/latest) |
| Windows 10 and 11 (x64), beta | `.exe` or `.msi` from [Releases](https://github.com/bernardopg/wingdrive/releases/latest). Unsigned, so SmartScreen warns |
| Headless server | `docker run -d -p 8080:8080 -v wingdrive-data:/data ghcr.io/bernardopg/wingdrive/server` |
| macOS | Build from source ([installation guide](../readme/installation.md)) |

<Note>
Linux is the supported platform. Windows installers are a beta. Signed macOS and Windows builds are planned for milestone M3.
</Note>

## Create Your First Library

<Steps>
<Step title="Open WingDrive">
On first launch the setup wizard opens.
</Step>
<Step title="Name the library">
Pick a name such as "Personal" or "Work". You can create more libraries later and switch between them from the library menu next to the page title.
</Step>
<Step title="Confirm">
The sidebar appears with Overview, Recents and Favorites.
</Step>
</Steps>

A library is a local database about your files: names, sizes, content identity, tags and devices. Files are never moved into it. To back up everything you organized, copy the library folder.

## Add Your First Location

A location is a folder that WingDrive watches and indexes. Adding one never moves or copies files.

<Steps>
<Step title="Open Add Storage">
On the Overview, click **Add Storage** at the top right, or **+** next to *Locations* in the sidebar.
</Step>
<Step title="Choose Local Folder">
Pick a folder. Start with something small, like Documents or Pictures.
</Step>
<Step title="Pick an indexing mode">
- **Shallow**: names and basic metadata only. The fastest.
- **Content**: adds BLAKE3 content identity, so duplicates and copies are recognized.
- **Deep**: adds media analysis and thumbnails. Use it for photo and video folders.
</Step>
<Step title="Follow progress">
The job manager (the sync icon at the bottom of the sidebar) shows indexing progress.
</Step>
</Steps>

![Overview with storage totals, devices, locations and volumes](/public/WingOverview.webp)

<Tip>
**Settings → Indexer** decides what new locations skip: system files, Git folders, build folders such as `node_modules`, hidden files, and paths listed in `.gitignore`.
</Tip>

## Find Your Way Around

![Grid view with the Inspector](/public/WingGridView.webp)

- **Sidebar**: Overview, Recents, Favorites, File Kinds, locations, volumes, devices and tags.
- **Explorer**: grid, list, columns, media and size views, with tabs (`Ctrl+T`) and two panes (`F3`).
- **Quick Preview**: press `Space` on a file.
- **Inspector** (`Ctrl+I`): details, permissions, SHA-256 and tags of the selection.
- **Search**: the magnifier in the top bar searches every indexed location and filters by kind, extension, size, date and hidden files.
- **Command palette** (`Ctrl+Shift+P`) and **Settings** (`Ctrl+,`).

Copy, move, trash, rename and new items are journaled: `Ctrl+Z` undoes the last one, and `wing file undo` does the same from the terminal.

## Organize with Tags

Tags organize files without moving them. Add them from the Inspector, or press `Alt+G` for tag mode and `1` to `0` to toggle the first ten tags on the selection. Click a tag in the sidebar to list its files. Tags sync to paired devices with the library.

## Connect Google Drive and Other Clouds

<Steps>
<Step title="Open Settings → Integrations">
Keep Google Drive and Google Photos checked, then click **Connect a Google account**.
</Step>
<Step title="Sign in in the browser">
After you allow access, the account's Drive appears in the sidebar. Repeat for more accounts.
</Step>
</Steps>

![Settings, Integrations](/public/WingIntegrations.webp)

S3 and compatible services, Dropbox, OneDrive, Azure Blob and GCS are added through **Add Storage → Cloud Storage** or `wing cloud`. See [Integrations](/core/integrations) and [Cloud integration](/core/cloud-integration).

## Connect Another Device

<Steps>
<Step title="Install WingDrive on the second device">
Use the same steps as above.
</Step>
<Step title="Pair">
On the first device, click **Pair → Generate Pairing Code**. On the second, click **Pair → Join with Code** and scan the QR code or type the 12 words. Codes expire after five minutes.
</Step>
<Step title="Set up sync">
Click **Setup Sync** to share the library. The index, tags and metadata sync; file contents stay where they are.
</Step>
</Steps>

There is no account and no central server: paired devices talk to each other directly over Iroh/QUIC, end-to-end encrypted. See [Pairing](/core/pairing) and [Library sync](/core/library-sync).

## Troubleshooting

### WingDrive won't start
- Run `wing status` to see whether the daemon answers.
- On a Wayland session with a GTK error, start it through XWayland: `GDK_BACKEND=x11 wingdrive`.
- Read the logs with `wing logs`.

### Indexing seems slow
- Use Shallow indexing for very large folders.
- Check that the disk is not full.
- Open the job manager, or run `wing job monitor`, for detailed progress.

### Can't see files
- Check that the location was added and its indexing job completed.
- Check that the right library is selected in the library menu.
