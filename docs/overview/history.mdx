WingDrive is an independent file management project developed and maintained
by Bernardo Pinto Gomes (`bernardopg`). Its canonical repository is
[bernardopg/wingdrive](https://github.com/bernardopg/wingdrive).

## Development

WingDrive builds on existing open-source work and maintains its own source,
releases, documentation, and development plan. The original source attribution
and licensing history are recorded in
[CREDITS.md](https://github.com/bernardopg/wingdrive/blob/main/CREDITS.md).

Development in this repository includes file operation fixes, filesystem
watching and indexing, Brazilian Portuguese translations, desktop integration,
and build and release automation. The Git history records each change and its
author. Plans and completed work are tracked in
[.tasks](https://github.com/bernardopg/wingdrive/tree/main/.tasks).

## Project ownership

The WingDrive repository is the source of truth for issue reports, pull
requests, releases, and documentation. Historical contributors remain credited
for the code they authored. Their presence in Git history does not imply
involvement in the current project.

Older service names, settings, and data paths remain readable so existing
installations can retain their libraries and configuration. New installations
use WingDrive names.
