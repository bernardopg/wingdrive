# WingDrive Documentation

Mintlify documentation for WingDrive. Pages are `.mdx` files; keep them current with the code.

## Structure

- `docs.json` - Mintlify configuration and navigation. Every page meant for readers must be listed here.
- `overview/` - product introduction and user guides.
- `core/` - core architecture, file management, sync and development guides.
- `core/design/` - design documents (`.md`) for subsystems still taking shape, such as Archive and Wingbot.
- `cli/`, `extensions/`, `react/ui/` - CLI reference, extension SDK and interface guides.
- `design/` - design notes and surveys; `design/history/` keeps dated audits that are evidence, not current status.
- `snippets/` - MDX components shared between pages.

`WRITING_GUIDE.mdx` and `CODE_COMMENTS.mdx` set the style for documentation and code comments.
