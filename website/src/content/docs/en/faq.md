## Is WingDrive free?

Yes. WingDrive is free and open source under the Apache License 2.0.

## Does WingDrive upload my files anywhere?

No. Indexing, thumbnails and search run on your machine. Data travels only between devices you pair yourself, end-to-end encrypted, or to cloud services you connect.

## Does it collect telemetry?

No. There is no account, no telemetry and no central server.

## Does adding a location move or copy my files?

No. A location is indexed where it is. WingDrive only changes files when you ask it to: copy, move, rename, delete.

## What happens when I unplug a drive?

Its files stay in the index, so you can still search them and see their metadata. Opening a file needs the drive, or another copy with the same content identity.

## Can I undo a mistake?

Copy, overwrite, cross-volume move and trash can be undone with Ctrl+Z or `wing file undo`. A file replaced by a copy is kept for 7 days.

## Which platforms are supported?

Linux is supported. Windows 10 and 11 are in beta. macOS builds from source until signed builds land in milestone M3. An Android preview ships with releases.

## Why does Windows warn about the installer?

The Windows installers are not signed yet. Choose *More info*, then *Run anyway*, and check the file against `SHA256SUMS-windows`. Signed releases are part of milestone M3.

## How do I report a bug or ask for a feature?

Open an [issue](https://github.com/bernardopg/wingdrive/issues/new/choose) or start a [discussion](https://github.com/bernardopg/wingdrive/discussions) on GitHub.

## How can I support the project?

Use it, report what breaks and spread the word. [Sponsoring on GitHub](https://github.com/sponsors/bernardopg) keeps development going.
