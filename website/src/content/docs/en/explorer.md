The Explorer is where you spend your day. It is built to be fast with a keyboard and calm to read.

| **List** | Code and documents: sortable columns, expandable folders, Git emblems |

Group a folder into sections by kind or date, show or hide hidden files (Ctrl+H) and filter the current folder (Ctrl+Shift+F).

## Quick Preview

Press **Space** on a file to preview it without opening another app: images, video, audio, PDF, text and code.

## Search

The search bar looks across every indexed location. Refine results by **kind**, **extension**, **size**, **date** and **hidden files**. The counts cover the whole result, not just the first page.

## Tabs, dual pane and terminal

- **Tabs**: Ctrl+T opens one, Ctrl+W closes it, Ctrl+Shift+T reopens the last.
- **Dual pane**: F3 splits the Explorer in two, to copy and compare side by side.
- **Docked terminal**: F4 shows a terminal under the view that follows the folder you are in. Shift+F4 opens your own terminal there. Pick the command in **Settings**; empty uses `xdg-terminal-exec`, `$TERMINAL` or an installed terminal.

## Git

In a repository, files and folders carry emblems for modified, added, untracked and ignored states, so the list view doubles as a quick `git status`.

## Tags

Tags organize without moving files. Press Alt+G to enter tag mode, then 1–9 and 0 toggle your first ten tags on the selection. Escape leaves tag mode.

## Keyboard shortcuts

On macOS, read Ctrl as Cmd.

| Action | Shortcut |
|---|---|
| Command palette | Ctrl+Shift+P |
| Settings | Ctrl+, |
| Quick Preview | Space |
| Rename | F2 |
| Open selection | Enter |
| Inspector | Ctrl+I |
| Focus path bar | Ctrl+L |
| Back / forward / parent | Ctrl+← / Ctrl+→ / Ctrl+↑ |
| Copy / cut / paste | Ctrl+C / Ctrl+X / Ctrl+V |
| Duplicate | Ctrl+D |
| Undo | Ctrl+Z |
| Move to trash / delete permanently | Delete / Shift+Delete |
| New folder / new file | Ctrl+Shift+N / Ctrl+Alt+N |
| Select all / invert / by pattern | Ctrl+A / Ctrl+Shift+I / Ctrl+S |
| Refresh | F5 |
| Hidden files | Ctrl+H |
| Dual pane | F3 |
| Terminal | F4 |
| New window | Ctrl+N |
