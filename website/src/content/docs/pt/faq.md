## O WingDrive é gratuito?

Sim. O WingDrive é gratuito e tem código aberto sob a Apache License 2.0.

## O WingDrive envia meus arquivos para algum lugar?

Não. A indexação, as miniaturas e a pesquisa são executadas na sua máquina. Os dados trafegam somente entre dispositivos que você mesmo emparelha, com criptografia de ponta a ponta, ou para serviços de nuvem que você conecta.

## Ele coleta telemetria?

Não. Não há conta, telemetria nem servidor central.

## Adicionar uma localização move ou copia meus arquivos?

Não. Uma localização é indexada onde está. O WingDrive só altera arquivos quando você solicita: copiar, mover, renomear ou excluir.

## O que acontece quando desconecto uma unidade?

Os arquivos permanecem no índice, então você ainda pode pesquisá-los e ver seus metadados. Para abrir um arquivo, é preciso conectar a unidade ou ter outra cópia com a mesma identidade de conteúdo.

## Posso desfazer um erro?

Cópias, substituições, movimentações, renomeações, envios à lixeira e novas pastas, arquivos e links podem ser desfeitos com Ctrl+Z ou `wing file undo`. Um arquivo substituído por uma cópia é mantido por 7 dias.

## Quais plataformas são compatíveis?

Linux é compatível. Windows 10 e 11 estão em beta. No macOS, a compilação é feita a partir do código-fonte até a chegada de versões assinadas no marco M3. Uma prévia para Android acompanha as versões lançadas.

## Por que o Windows exibe um aviso sobre o instalador?

Os instaladores para Windows ainda não são assinados. Selecione *More info* e depois *Run anyway*, e confira o arquivo com `SHA256SUMS-windows`. Versões assinadas fazem parte do marco M3.
