# Security Policy

## Reporting a Vulnerability

Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/bernardopg/wingdrive/security/advisories/new).
Do not open a public issue for a vulnerability that has not been disclosed.

Include the affected version, platform, reproduction steps, impact, and any
suggested mitigation. The WingDrive maintainer will acknowledge the report and
coordinate disclosure through the advisory.

Reports sent to the security contacts of the original project do not reach
the WingDrive maintainer. If GitHub is not an option, email
[bernardo.gomes@bebitterbebetter.com.br](mailto:bernardo.gomes@bebitterbebetter.com.br)
with "WingDrive security" in the subject.
